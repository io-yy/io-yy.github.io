# idunno 書評網站

## 檔案結構
```
根目錄/
├── index.html           ← 首頁
├── about.html           ← 關於頁面
├── banner.jpg           ← 首頁 Banner 圖片（自行上傳）
├── taiyang-cover.jpg    ← 太陽依舊升起書封（自行上傳）
└── reviews/
    ├── taiyang.html     ← 太陽依舊升起書評
    └── template.html    ← 新書評範本
```

## 新增書評步驟
1. 複製 reviews/template.html，改檔名
2. 修改書名、作者、內文
3. 上傳到 reviews/ 資料夾
4. 在 index.html 新增一個 book-card 區塊
